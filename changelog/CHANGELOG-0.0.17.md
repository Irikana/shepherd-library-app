# SlyWrite 更新日志

## 0.0.17（2026-09-19）

与 0.0.16 相比的净变更：「全部更新日志」页的版本时间条修好两处——选中标记不再整体右偏，
从时间条跳转后该版本会保持选中。

### 修复

- **时间条的选中标记整体偏右，压不到版本节点上**：节点中心按「左内边距 + 序号 × 节点宽 + 半格」计算，
  而节点本身是轨道的行内子元素、轨道并没有那个左内边距，于是游标与进度线的坐标空间比节点多出一截，
  恒偏右 14px 且不随序号增长（偏量小于一格，看着就是「永远差一点」）。现把两者统一到同一坐标空间：
  节点中心只按序号与节点宽计算，原来的左内边距改为只作轨道末端留白。
- **从时间条点选版本跳转后不会选中该版本**：跳转是带动画的滚动，飞行途中列表滚动事件连续触发，
  按中间位置反推出的版本会把刚点选的那个覆盖掉；更糟的是越靠后的版本（越旧的日志）滚到底也顶不到视口顶部，
  反推结果会永久停在更新的版本上，表现为「点了没反应 / 过一会儿自己跳走」。现加跳转锁：
  跳转期间不做反推，以点击的版本为准，动画落定后超时兜底解锁，用户一接手拖动列表立即恢复正常联动。

### 版本与构建

- 版本号 `0.0.16` → `0.0.17`（`package.json` / `app.json` 两处同步）；第四位构建号仍只由 CI 注入。
- 按 2026-09-19 起的新发版规则（每批用户可见改动即一次发版），本批提交后随即打 tag `v0.0.17`。
