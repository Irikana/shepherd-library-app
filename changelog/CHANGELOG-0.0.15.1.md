# SlyWrite 更新日志

## 0.0.15.1（2026-08-10）

与 0.0.15 相比的净变更：

### 修复

- **隐藏文章偶发残留（关键修复）**：此前编辑页/发布页隐藏文章时，各同步步骤（library.html 中英文、新闻板块 index.html/news.html/en/index.html）独立 try/catch 静默失败——文章文件写入隐藏标记成功，但公开列表移除失败只记一条提示、不报错不重试，导致已隐藏文章仍残留在主页/新闻区/列表页。现已修复：
  - **同步逻辑抽为可重试函数** `syncVisibility`（editor.tsx），保存流程与「重试同步」共用同一份逻辑
  - **失败可见**：保存后 Alert 明确列出失败步骤；有失败时提示「可点击『重试同步』再次执行」，重试成功/失败均有明确反馈
  - **发布流程失败标红**：preview.tsx 结果日志中失败步骤以「[失败]」前缀突出显示
  - **网站残留已清除**：隐藏文章「测试新闻20260802N1」在 index.html / news.html / en/index.html / library.html / en/library.html 的残留卡片与列表条目已全部移除
- **国内镜像下载进度卡 0（关键修复）**：原镜像 `ghproxy.com` 已失效（301 跳转 ghfast.top，后者仍 302 回 GitHub），下载时镜像不返回 Content-Length，进度永远 0%。现已修复：
  - 镜像更换为 `gh-proxy.com`（实测可用、返回完整 Content-Length）
  - 镜像下载失败自动回退 GitHub 官方直连（保留原逻辑）
  - 进度兜底：镜像不返回总大小时进度条显示「下载中…」（不确定态），不再卡 0%

### 新增

- **知识馆词条撰写功能**：SlyWrite 新增「撰写知识词条」入口（首页功能卡片），支持为知识馆（现象 / 可回忆知识 / 可追溯知识）创建词条页：
  - 词条信息：中文标题 + 英文标题（文件名）+ 近义词/别称 + 知识分类 + 创建日期 + Markdown 正文
  - 词条页生成：基于知识馆词条模板（kh-body 布局 + 侧边栏导航 + 词条元数据 + 知识关系图谱），自动适配相对路径
  - 自动同步：发布后上传词条页至 `knowledge-hall/categories/{分类}/xxx.html`，并更新对应分类页的词条列表（首次插入替换"暂无条目"提示框，之后追加至列表，防重复）
  - 草稿支持：知识词条自动保存草稿（草稿箱恢复时自动分流到词条撰写页）

### 其他

- **版本号规则变更**：自 0.0.15 起每次工作只自增第四位（0.0.15 → 0.0.15.1 → 0.0.15.2），除非特别强调否则不改前三位；本技能已同步更新（slywrite-changelog-release）
- 版本号提升至 0.0.15.1（package.json / app.json / CI artifact name 三处同步）；app.json 新增 android.versionCode=2（保证覆盖安装）
- compareVersions 支持四段版本号比较（App 内可正确识别 0.0.15.1 > 0.0.15）
- 网站链接双重箭头清理：chapter 系列（chapter-02 ~ chapter-20）与 answer-01 中链接文本的手动「←」箭头移除（与 CSS 自动箭头重叠），全站统一由 CSS 控制
