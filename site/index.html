SlyWrite
牧羊人图书馆 · 写作管理

简介

SlyWrite 是牧羊人图书馆的移动端写作管理 App（Android），用于在手机上撰写文章与新闻，并一键同步到图书馆网站。

当前版本：v0.0.5
通过下方按钮下载安装包（APK）。安装前请允许安装未知来源应用。

功能

撰写文章：双标题（中文显示 + 英文文件名）、文章性质（录音/手写/信息/实验性）、标签、脚注、数学公式；分类上传并自动同步中英文 library.html 文章列表。

新闻发布：完整元数据（性质/标签/日期/脚注）+ 正文分段编辑，可选海报（原图上传）；自动同步主页新闻区、news.html 与英文主页。

草稿箱：撰写内容自动保存，退出重进后可恢复继续编辑。

内容编辑：浏览仓库文件树，编辑已有文章/新闻——元数据表单 + Markdown 正文 + 源码三种方式。

设置：浅色 / 深色 / 跟随系统主题切换。

更新检查：在 App 内直接检查最新版本并下载。
